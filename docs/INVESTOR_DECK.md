## Slide 5 — How it works (creator flow)

### From PDF to course in minutes

1. **Upload** — PDF, Word, slides, images, audio, video (with transcription)  
2. **Build** — Live progress UI; AI plans outline → writes lessons → generates quizzes  
3. **Review** — Edit lessons, refine with natural language, add images  
4. **Publish** — Private self-study, share link, or list on Explore  

**Self Study mode:** User describes their goal (“O-chem exam in 2 weeks”) → AI calibrates depth and structure.

---

## Slide 6 — How it works (learner flow)

### Two ways to learn the same course

**Mentored Learning** (immersive)  
- Rose teaches in chunks: explain → check question → advance  
- Voice-first (hold-to-talk or live conversation)  
- Side-by-side source material + auto-generated notes  

**Free Exploration** (self-paced)  
- Full course reader with sidebar navigation  
- Highlights → personal quiz cards  
- Module quizzes, practice again, course-wide mix  
- Voice dock: “Take me to the module on X” — Rose navigates  

**Mode persists per course** — resume exactly where you left off.

## Slide 7 — Tutor Sessions (differentiator)

### ChatGPT can talk. Rose can *tutor* — with your files open.

Standalone sessions for when you don’t need a full course:

- **Topic + up to 20 reference files** (PDFs, screenshots, notes)  
- **Modes:** Exam prep · Homework help · Concept review · Quiz me · Exploring  
- **Live notes panel** — AI-synthesized study notes (not transcript dumps)  
- **Voice conversation** with barge-in, resume, echo filtering  
- **End session → recap** → share, edit, or **convert session into a course**  

*Homework at 11pm. Lecture slides from yesterday. One session, one recap, optional course.*

## Slide 8 — Retention engine

### Learn once, remember until the exam

| Layer | Mechanism |
|-------|-----------|
| **Module quizzes** | MCQ + AI-graded free response; wrong-answer retry |
| **Personal / Focus quiz** | Generate questions from *your* highlights and notes |
| **Spaced repetition (SRS)** | SM-2 scheduling; global review dashboard |
| **Progress** | Module completion, accuracy rings, 14-day activity heatmap, streaks |

**The loop:** Read → highlight → personal cards → daily review → module quiz → complete.

## Slide 14 — Technology (high level)

- **Stack:** Next.js, Supabase (auth, DB, storage), Anthropic Claude, Deepgram, ElevenLabs  
- **Architecture:** Streaming SSE for tutor turns; background ingest jobs for large PDFs/video  
- **Grounding:** Rose’s answers constrained to uploaded material + session transcript  
- **Memory:** Running discussion summaries + transcript persistence for long sessions  

**Defensibility over time:** User progress graph, personal quiz banks, session history, creator catalog on Explore.
